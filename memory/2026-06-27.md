### Key Technical Details
- Audio pipeline: Twilio mulaw 8kHz → mulawDecode → PCM16 → WAV → PolarGrid Whisper STT
- TTS: PCM24 from PolarGrid → FIR low-pass resample to 8kHz → alawmulaw.encodeSample() & 0xff → mulaw → Twilio
- **Critical bug fixed:** alawmulaw.encodeSample() returns signed int8, must mask with & 0xff
- Audio now paced to real-time (40ms chunks with 40ms sleep) so Twilio and server stay synchronized — no post-send wait guessing
- VAD: 300 RMS threshold, 120ms silence window (400ms when expecting phone number), 60ms min speech gate
- Post-TTS cooldown: 200ms after real-time paced playback completes
- Barge-in threshold: 8x VAD_SILENCE_RMS
